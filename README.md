# Sebastian Graham — Portfolio

Personal engineering portfolio built with React and Vite.

## Development

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run deploy` publishes the production build to GitHub Pages.

The main content is in `src/pages/home.jsx`; styling is in `src/index.css`.

School resources are paused. Their original PDFs are preserved in `archive/materials`, outside the public directory so they are not included in future deployments. The old page and data remain in `src/pages/materials.jsx` and `src/data/materials.js` for reference, but are not imported or routed by the site.
